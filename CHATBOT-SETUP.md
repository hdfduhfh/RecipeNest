# Recipe Guide in the Browser

Open `index.html` with Live Server and click **Ask Nest** in the bottom-right corner. The chat panel automatically uses the supplied recipe data; no configuration is required.

Try asking:

- “Meals under 20 minutes”
- “Vegetarian ideas”
- “Ingredients for lemon-pasta for 6 people”
- “How to cook lemon-pasta”
- “How do I plan my meals?”

You can switch between the six website languages. The guide uses keyword matching and sample data rather than free-form AI conversation. Messages are not sent to an external service.
