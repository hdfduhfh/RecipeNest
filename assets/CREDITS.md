## Language picker design

The round flag trigger, dropdown styling and EN/VI/JA/ZH/FR SVG flags are adapted from the user-supplied Sweet Bakery reference project. The Hindi/India flag SVG is a local vector addition for RecipeNest. This adaptation uses the existing RecipeNest translations and does not import Sweet Bakery backend or account features.
